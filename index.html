About

I'm an electrical and computer engineering student at NYU Tandon, and I've never been satisfied knowing that something works without knowing why. That itch pulled me from writing programs to questioning what actually runs them, so I built my own answer: an 8-bit CPU in Verilog with a cache hierarchy and virtual memory, then carried it from RTL through a verified Sky130 core layout.

The pattern repeats everywhere I work. At Generex I build protocol and sensor firmware that is tested off-device before it is proven against real hardware. At Tokonoma I build infrastructure that lets AI agents investigate production incidents. Each layer I learn makes the one below it more interesting, and the bottom of that stack is chip design. That's where I'm headed.

Spherra

A local, embedded vector index in Rust for 768-dimensional embeddings. Each vector goes through a randomized Hadamard rotation so its coordinates are about the same size, then gets rounded to a small grid with a stored correction, shrinking it from 3,072 bytes to 484. Search runs only on the compressed copies, and every result comes with a proven range that contains its true score. Commits are crash-safe, and rows can be appended later.

Project datasheet · digital design Verilog · FPGA · Sky130

8-bit CPU: RTL to GDS

I designed a complete 8-bit Harvard-architecture CPU in Verilog with a 12-instruction ISA, write-back L1 and 4-way set-associative L2 caches, and virtual memory through a 4-entry TLB and cache-mediated MMU. The RTL, assembler, integration programs, and Basys3 wrapper are covered by the project's regression flow. I then hardened the core through OpenROAD into a via-complete Sky130 HD GDS with clean timing, route checks, standalone KLayout DRC, and project-deck electrical LVS. It is a verified core block, not a fabricated or foundry-signed-off chip.
